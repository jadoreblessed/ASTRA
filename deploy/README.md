# Запуск ASTRA на сервере

Без Docker: обычный Ubuntu, Postgres, Node, Caddy (сам делает HTTPS) и systemd.
Весь запуск занимает минут 15, и скрипт всё ставит сам.

## Что нужно заранее

- **Сервер:** Ubuntu 24.04 (или 22.04), 2 ГБ памяти, 20 ГБ диска. Hetzner, DigitalOcean, что угодно.
- **Домен:** в DNS запись `A` на IP сервера. Без неё HTTPS не поднимется, так что сделай это первым.
  Домена пока нет? Вместо него дай IP сервера, и сайт откроется по http. Когда домен появится, запусти `setup.sh` ещё раз уже с доменом: ключи и база останутся, добавится HTTPS.
- **0.05 SOL** на vault, это на шаге 5.
- Код должен быть в git: всё, что не запушено, на сервер не приедет.

## 1. Зайти на сервер и забрать код

```bash
ssh root@IP_СЕРВЕРА
```

```bash
apt-get update && apt-get install -y git
```

```bash
git clone https://github.com/jadoreblessed/ASTRA /opt/astra
```

## 2. Поставить всё одной командой

Подставь свой домен и хендл в X (хендл без `@`, можно не указывать):

```bash
bash /opt/astra/deploy/setup.sh твойдомен.com astra_handle
```

В конце он напишет адрес сайта и адрес vault. Торговля в этот момент выключена, купить никто ничего не может.

## 3. Сохранить ключ. Это самый важный шаг

```bash
grep -E 'MASTER_KEY|VAULT_SEALED' /etc/astra/astra.env
```

Скопируй обе строки в менеджер паролей, не на этот сервер. `MASTER_KEY` открывает vault и email-кошельки: потеряешь его вместе с сервером, и деньги пропали. Утечёт — тоже. В чат, в git и в скриншоты он попадать не должен.

Ключ от админки:

```bash
grep ADMIN_TOKEN /etc/astra/astra.env
```

Админка живёт на `https://твойдомен.com/admin`: CA, X, Telegram, пауза торговли, вывод комиссии, buyback.

## 4. Настройки

Кошелёк, куда выводится комиссия. Лучше всего твой холодный, потому что вывод идёт только на него:

```bash
bash /opt/astra/deploy/set.sh TREASURY_WALLET АДРЕС_КОШЕЛЬКА
```

RPC от Helius, бесплатный ключ на helius.dev. Публичный RPC под нагрузкой теряет транзакции, так что ставить стоит:

```bash
bash /opt/astra/deploy/set.sh SOLANA_RPC_URL "https://mainnet.helius-rpc.com/?api-key=ТВОЙ_КЛЮЧ"
```

Вход по email (необязательно). Без ключа Resend кнопка email просто скрыта, кошельки работают:

```bash
bash /opt/astra/deploy/set.sh RESEND_API_KEY ТВОЙ_КЛЮЧ
```

## 5. Пополнить vault

Отправь **0.05 SOL** на адрес vault, который написал `setup.sh`. Адрес всегда можно посмотреть так:

```bash
curl -s http://127.0.0.1:8080/api/config | grep -o '"vault":"[^"]*"'
```

Больше туда руками ничего не отправляй. Сеть оплачивают покупатели, а 0.05 это потолок того, что платформа может потратить сама: шесть готовых корзин стоят около 0.036 SOL, остальное в запасе.

## 6. Включить торговлю

```bash
bash /opt/astra/deploy/set.sh TRADING_ENABLED true
```

## 7. Первый тест

Заказ пока ограничен $2, этого хватит.

1. Купи любую корзину на $1 своим кошельком. В кошельке будет одна транзакция: USDC или SOL на vault.
2. Подожди, пока заказ станет `filled`, и проверь, что доли пришли.
3. Сделай redeem и проверь, что токены вернулись на кошелёк.
4. Открой `/admin`: там видно потраченный SOL, комиссию и то, что требует внимания.

Если всё хорошо, подними лимит заказа:

```bash
bash /opt/astra/deploy/set.sh MAX_ORDER_USD 50
```

## Каждый день

| Что | Команда |
|---|---|
| Статус сервисов | `systemctl status astra-api astra-worker astra-signer astra-web` |
| Логи | `journalctl -u astra-worker -f` |
| Обновить код после пуша | `bash /opt/astra/deploy/update.sh` |
| Сменить настройку | `bash /opt/astra/deploy/set.sh ИМЯ значение` |
| Быстро остановить покупки | кнопка паузы в `/admin` |

Резервная копия базы делается каждый день в `/var/backups/astra`, хранится 14 дней. Лучше иногда забирать её с сервера.

## Если что-то пошло не так

- **Сайт не открывается по HTTPS:** проверь запись `A` у домена и посмотри `journalctl -u caddy -n 50`.
- **Сайт есть, данных нет:** `journalctl -u astra-api -n 50`.
- **Заказ завис:** `/admin`, блок «Needs attention». Там же кнопка повтора выплат.
- **Покупки отказывают:** проверь `TRADING_ENABLED`, паузу и баланс vault.
